How to use Tunnel Vision

  • Press Ctrl + Alt + L to toggle the screen
  • Or click the extension icon and use the Screen On/Off button
  • Ctrl + Up / Ctrl + Down — move highlight
  • Also works with Ctrl + J / Ctrl + K
  • When screen is ON click a line to highlight it
  • While the screen is ON, if you want to click line without activating any link, hold down Alt (useful on sites like X.com)
  • You can select text like normal when the screen is ON
  • Select text while screen is OFF and it will be highlighted when turned ON
  • While the screen is ON, hold Alt and use the scroll wheel to increase/decrease the screen opacity
  • While the screen is ON, hold Ctrl and click and drag to create a highlight box to block out everything but one part of the screen
  • If it is a site where everything is a link (like x.com) hold Ctrl + Alt and click and drag to create the highlight box
  • Press Sound On/Off button to toggle the sound which plays when moving up/down a line
  • Press Ctrl + Alt + m to turn on mouse highlighting
